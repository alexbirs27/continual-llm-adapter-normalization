\headerbox{1. Introduction}{name=problem,column=0,span=1}{

Continual learning requires a model to sequentially acquire knowledge across multiple tasks
without forgetting what it previously learned. A common challenge is \textbf{catastrophic
forgetting}: adapting to a new task overwrites representations built for earlier ones.

When parameter-efficient methods such as \textbf{LoRA} are applied in this setting, the
low-rank adapter matrices trained on successive tasks tend to occupy overlapping subspaces,
causing destructive interference.

\textbf{O-LoRA} addresses this by imposing an orthogonality constraint
on the $A$ matrices of each new task adapter with respect to all previously learned ones,
ensuring each task projects inputs into a distinct region of the low-rank latent space and
limiting the interference that drives forgetting.

}

\headerbox{2. Dataset and Preprocessing}{name=sketch,column=0,below=problem,span=1}{

\textbf{Task sequence (fixed order):}
\begin{compactitem}
  \item \textbf{AG News} -- 4-class news topic classification
  \item \textbf{Amazon Polarity} -- binary sentiment classification
  \item \textbf{DBpedia 14} -- 14-class Wikipedia topic classification
  \item \textbf{Yahoo Answers Topics} -- 10-class question topics
\end{compactitem}
Each task is trained on independently, with no replay of prior task data.

\textbf{Instruction-tuning prompt format:}
\begin{center}\small
\begin{tabular}{l}
\toprule
\texttt{\{task instruction\}\textbackslash n}\\
\texttt{Option: \{comma-separated label names\}\textbackslash n}\\
\texttt{\{input text\}\textbackslash n}\\
\texttt{Answer:}\\
\bottomrule
\end{tabular}
\end{center}
Only the input text is truncated when the sequence exceeds the maximum length of 256. Cross-entropy
loss is computed only on the label token; at evaluation the predicted label is the candidate
label token with maximum logit at the position before \texttt{Answer}.

}




\headerbox{3. Models}{name=architecture,column=0,below=sketch,span=1}{

\textbf{Backbone:} Qwen2.5-1.5B. \textbf{LoRA:} rank $r{=}8$, $\alpha{=}32$, dropout 0.1,
on $Q,V$ of every attention layer. \textbf{Optim:} 1 epoch/task, lr $10^{-3}$, batch 8.

\vspace{0.3em}
\textbf{Compared methods:}
\begin{compactitem}
  \item \textbf{IncLoRA} -- separate frozen adapter per task ($\text{BWT}=0$ by construction).
  \item \textbf{O-LoRA} -- one cumulative adapter; orthogonality penalty between the new
        task's $A$ and all previous ones, weighted by $\lambda_1 \in [0.2, 0.3]$.
\end{compactitem}

\vspace{0.2em}
\textbf{Orthogonal loss.} For task $t$ with $\Delta W_t = B_t A_t$:
\[
\mathcal{L}_t = \mathcal{L}_{\mathrm{CE}}(A_t,B_t)
+ \lambda_1 \!\!\sum_{i<t}\bigl\lVert A_t A_i^{\!\top}\bigr\rVert_F^{2}
\]
The penalty drives row-spaces of successive $A$ into orthogonal directions.
}

\headerbox{5. Orthogonality Analysis}{name=ortho,column=1,below=res,span=2}{

Three pairwise metrics across task adapter matrices: cosine similarity, Gram Frobenius norm
$/r$ (the quantity minimised by O-LoRA), and max principal angle cosine.

\vspace{0.3em}
\begin{center}
\includegraphics[trim=10 5 10 25,clip,width=0.94\textwidth]{task_similarity_A_8h.pdf}\\[2pt]
{\footnotesize Task-pair similarity of $A$ matrices (8h): \textbf{all metrics near-zero
off-diagonal} -- $A$ matrices are geometrically separated.}
\end{center}

\vspace{0.3em}
\textbf{Layer-wise breakdown ($A$ vs $BA$).} A different view -- per-layer mean inter-task
similarity. The constraint holds across all transformer blocks for $A$ (left). The same
cosine and Gram Frobenius metrics are also applied to the full weight update
$\Delta W = BA$. For these product matrices the Frobenius norm is reported \emph{without}
rank normalisation -- would scale values by up to $192\times$ depending on the module.
\begin{center}
\includegraphics[trim=20 10 20 15,clip,width=0.48\textwidth]{layer_orthogonality_A_8h.pdf}\hfill
\includegraphics[trim=20 10 20 15,clip,width=0.48\textwidth]{layer_orthogonality_AB_8h.pdf}
\end{center}

\vspace{0.1em}
$B$ matrices are unconstrained: they share $\sim 30\%$ of their column-space directions
(principal-angle cosine $\sim 0.29$) and grow in magnitude with training. 

}


\headerbox{6. Conclusion}{name=conclusion,column=1,below=ortho,span=2}{
\begin{compactitem}
  \item $A$ matrices are \textbf{geometrically separated} with mild penalties, uniformly
        across every layer.
  \item Extending the constraint to all six projection modules ($q,k,v,o,$ up, down): $A$
        keeps a \textbf{similar degree of inter-task orthogonality regardless of the
        targeted module}.
  \item Forgetting is \textbf{highly sensitive to data scale}: BWT $-0.032$ at 500
        samples/task, $-0.268$ at $\sim$50\% of the paper's scale. \textbf{Prompt structure
        $>$ hyperparameters}: $+0.20$ Avg Acc, $+0.25$ BWT. \textbf{Future work}:
        regularise $B$ or constrain $\lVert BA\rVert$ directly.
\end{compactitem}
}
